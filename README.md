# 🗡️ BDO Tracker v4

黒い砂漠向けの記録・管理ツールです。金策セッションの記録、馬捕獲カウント、デイリー/ウィークリータスク管理などをまとめて行えます。

---

## 📋 主な機能

### 💰 金策タブ
- **記録** — 狩場・活動ごとに時間・ゴミドロ数 or シルバーを記録。セッション開始/終了タイマー付き
- **デイリー** — 日別の収支グラフと集計（期間フィルター対応）
- **グラフ** — 過去セッションの推移をビジュアル表示
- **ランキング** — 狩場別の時給ランキング（月別フィルター・並び替え対応）
- **履歴** — 過去セッション一覧・狩場スポット管理

### 🐎 馬タブ
- 今日の捕獲数 / 累計捕獲数の記録
- 日別捕獲数グラフ

### 🎯 目標タブ
- 手持ち資産の管理
- 目標金額の設定とプログレスバー表示

### ✅ タスクタブ
- 期限付き・デイリー・ウィークリータスクの管理
- 自動リセット機能（デイリー/ウィークリー）

### 🖥️ HUD（常時最前面表示）
- 今日の馬捕獲数をゲーム中にオーバーレイ表示

### ⌨️ ホットキー
| キー | 動作 |
|------|------|
| `F9` | 馬捕獲 +1 |
| `F10` | 直前の捕獲を取り消し |
| `F8` | HUD 表示/非表示切り替え |

## 🚀 セットアップ（ソースから実行）

### 必要なもの
- Python 3.10 以上
- 以下のライブラリ

```bash
pip install customtkinter matplotlib keyboard
```

### 起動方法

```bash
python main.py
```

## 🔧 v4 の変更点（パフォーマンス改善）

v4 ではUIの重さ・操作レスポンスを大幅に改善しました。

- **フォントキャッシュ化**（`constants.py`）  
  `CTkFont` の過剰生成（115回）をキャッシュで抑制。同じサイズ・ウェイトは同一インスタンスを使い回すように変更。

- **タスクタブの差分更新**（`task_tab.py`）  
  `refresh()` のたびに全ウィジェットを破棄→再生成していた処理を、セクションヘッダーを固定しアイテムのみ入れ替える方式に変更。

- **目標タブのラベル更新のみに変更**（`goal_tab.py`）  
  プログレスバー含むカード全体を毎回再構築していた処理を、目標の追加・削除時のみ再構築、通常更新は `.configure()` のみに変更。

- **ランキングタブのDBキャッシュ化**（`ranking_tab.py`）  
  並び替え切り替えのたびにDBアクセスが走っていた処理をキャッシュし、ウィジェットも再利用するように変更。

- **タブ切り替えコールバックの修正**（`app.py`）  
  タスクタブの `command` 漏れを修正し、`update_total()` の遅延更新ロジックを整理。

- **デイリータブのコンボボックス修正**（`daily_tab.py`）  
  期間コンボの `command` 漏れを修正し、`refresh_filter()` で `.set()` を明示呼び出しに統一。

## 📝 メモ

- `.db` ファイルと `.json` ファイルはアプリ起動時に自動生成されます
- `spot.json` は狩場データのカスタマイズファイルです（手動追加可能）
- `bdo_settings.json` には最後に選択した狩場・目標金額などが保存されます
- PyInstaller の `.spec` ファイルが同梱されているので、単体 `.exe` のビルドも可能です

```bash
pyinstaller BDO_Tracker.spec
```
